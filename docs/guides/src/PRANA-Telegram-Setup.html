◈What you're building

After this guide, PRANA is a Telegram bot on your phone: chat with it, give it tasks, and — the real magic — it can message you first when scheduled jobs finish. No tunnel needed: Telegram's Bot API is polled from your machine.

Paste API key (hidden): ••••••••••••
2
Create your bot with @BotFather
👆 YOUR 2-MIN STEP

On your phone, in Telegram:

  1. Open a chat with @BotFather → send /newbot
  2. Pick a display name (e.g. PRANA)
  3. Pick a username ending in bot (e.g. my_prana_bot)
  4. BotFather replies with your token — long string like 123456:ABC-DEF…. Copy it.
💡 Tip
Token leaked or shared by accident? /revoke in @BotFather instantly kills it and issues a new one.
3
Give PRANA the bot token
🤖 AUTOMATIC

Recommended (persistent): add to %USERPROFILE%\.prana\config.json:

%USERPROFILE%\.prana\config.json
{
  "telegram": { "bot_token": "123456:ABC-DEF...paste..." }
}

Alternative (this session only): $env:TELEGRAM_BOT_TOKEN="..." in PowerShell. The token is never logged — error paths name the method, never the URL.

The getMe handshake validates your token at startup — a bad token fails fast with a clean error, never a hang.

5
Proactive pings — the "alive" part 🫁
🤖 AUTOMATIC

This is what makes PRANA different from a chatbot: it messages you first.

  1. Message @userinfobot on Telegram → it replies with your numeric chat id
  2. Schedule a job targeting it (from any PRANA chat, or via the schedule tool):
PRANA chat
you: schedule a job "morning-brief" every day at 8am: summarize the top tech news. Send it to telegram:987654321
scheduled 'morning-brief' → job id 27e8f0a2…  delivery: telegram:987654321

Run prana-daemon alongside prana-telegram: the daemon runs due jobs, the delivery decision filters noise, and real changes land on your phone. Unchanged results stay silent — no spam, ever.

✓Verify it works

  • Open your bot in Telegram → /start → intro message arrives
  • /help → command list (answered locally — zero tokens spent)
  • Send a task: "summarize what you can do" → real answer
  • Schedule a test ping (Step 5) → message arrives without you asking

✚Troubleshooting

Error / symptomFix
error: no Telegram bot token — set TELEGRAM_BOT_TOKEN…Token not found. Check telegram.bot_token in config.json or the TELEGRAM_BOT_TOKEN env var in the same terminal.
error: bot token rejected by TelegramWrong or revoked token. @BotFather → /revoke → copy the new token.
409 Conflict on getUpdatesAnother instance is polling with the same token (old terminal still running?). Kill the duplicate — only one poller per bot.
Bot ignores group messagesGroup privacy mode. @BotFather → /setprivacy → Disable, or mention the bot explicitly.
Long replies arrive in piecesNormal — Telegram caps messages at 4000 chars; PRANA chunks losslessly, preferring paragraph breaks.
ℹ️ Built-in resilience
One bad update never kills the listener. Offsets persist in ~/.prana/telegram.json, so restarts don't re-process old messages. /start and /help are answered locally without touching your API key quota.
