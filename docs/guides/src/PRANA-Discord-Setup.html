◈What you're building

After this guide, PRANA is a bot on your Discord server: message it in any channel, it runs its full brain (ReAct loop, shell/files/web tools, memory, per-channel conversation history), and replies. Built on raw Discord Gateway + REST over stdlib only — no discord.py needed.

1
Install PRANA
🤖 AUTOMATIC

Open PowerShell and run:

PowerShell
$ git clone https://github.com/Thegreatprabh/Prana.git
$ cd Prana
$ python -m pip install -e .
# use `python -m pip` (not bare `pip`) — on some machines they point to different Pythons
2
Save your AI key (BYOK)
🤖 AUTOMATIC
PowerShell
$ prana --save-key
Paste API key (hidden): ••••••••••••
API key saved for openai → C:\Users\YOU\.prana\config.json (0600)

Provider auto-detected from the key prefix. The key is never logged or echoed.

3
Create the Discord application
👆 YOUR 2-MIN STEP
  1. Go to discord.com/developers/applications → New Application
  2. Name it (e.g. PRANA) → Create

That's the app shell. The bot identity comes next.

4
Copy the bot token
👆 YOUR 2-MIN STEP
  1. Open the Bot tab → click Reset Token → Copy
⛔ Treat it like a password
Discord shows the token exactly once. Anyone with it controls your bot. Never paste it in a chat, screenshot, or public repo.
🫁 PRANA Discord Setup Guide
5
Enable the Message Content intent
👆 YOUR 2-MIN STEP

Still on the Bot tab, scroll to Privileged Gateway Intents and turn ON:

✅ MESSAGE CONTENT INTENT

⛔ The #1 reason bots look dead
Without this toggle, Discord delivers every message with empty text — PRANA connects fine but never "hears" anything. If your bot is online but silent, this is the cause 99% of the time. Toggle it, then restart prana-discord.

PRANA requests intents value 37377 = GUILDS · GUILD_MESSAGES · DIRECT_MESSAGES · MESSAGE_CONTENT.

6
Invite the bot to your server
👆 YOUR 2-MIN STEP
  1. OAuth2 → URL Generator → check scope bot
  2. Under Bot Permissions check: Send Messages + Read Messages/View Channels
  3. Open the generated URL → pick your server → Authorize

You need Manage Server permission on the server to invite bots.

7
Give PRANA the token & start it
🤖 AUTOMATIC

Recommended (persistent): add to %USERPROFILE%\.prana\config.json:

%USERPROFILE%\.prana\config.json
{
  "discord": { "bot_token": "MTIz...paste-your-bot-token..." }
}

Alternative (this session only): $env:DISCORD_BOT_TOKEN="..." in PowerShell.

Then start the listener:

PowerShell
$ prana-discord
🤖 connected as @PRANA — listening on Discord

The startup handshake validates your token (/users/@me) before listening — a bad token fails fast with a clean error, no hanging.

✓Verify it works

  • Type !help in a channel → instant command list (zero tokens)
  • Send a normal message → PRANA thinks and replies in the channel
  • Give it a task: "summarize what you can do"
  • History is per-channel — it remembers each thread

✚Troubleshooting

Error / symptomFix
error: no Discord bot token — set DISCORD_BOT_TOKEN…Token not found. Check discord.bot_token in config.json or the DISCORD_BOT_TOKEN env var in the same terminal.
error: Discord rejected the bot tokenToken is wrong or was regenerated. Bot tab → Reset Token → copy the new one.
Bot is online but never repliesMessage Content Intent is OFF. Bot tab → enable it → restart prana-discord. (The #1 cause.)
gateway: invalid session (bad token?)Token invalid — reset and replace it.
gateway: timed out waiting for READYNetwork/firewall blocking Discord's gateway. Check connectivity; the listener retries with backoff automatically.
Bot can't see a channelRe-check the invite URL permissions, and the channel's own permission overrides for the bot's role.
Replies are split into piecesNormal — Discord caps messages at 2000 chars; PRANA chunks long replies losslessly.
ℹ️ Built-in resilience
Dropped gateway connections reconnect automatically with backoff (1s → 30s max). One bad message never kills the listener. PRANA never replies to its own messages.
