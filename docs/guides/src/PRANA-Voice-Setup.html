After this guide: hold the mic button in your PRANA Telegram chat, speak, and get a spoken reply back — playable audio, not just text. The agent hears you via Whisper, thinks with its full brain, and answers with an OpenAI voice.

1
Get Telegram working first
🤖 AUTOMATIC

Voice rides on the Telegram channel. If you haven't done it yet, follow the PRANA Telegram Setup Guide (Guide 3 of 5) — bot token, prana-telegram, /start working.

2
Save an OpenAI key
👆 YOUR 2-MIN STEP

Voice needs OpenAI specifically — Whisper for hearing, TTS for speaking. (Your chat brain can still be any provider.)

PowerShell
$ prana --save-key
Paste API key (hidden): ••••••••••••
# paste an OpenAI key (starts with sk-) — auto-detected as "openai"

Get one at platform.openai.com → API keys. PRANA looks for the OpenAI key in this order: --key flag → OPENAI_API_KEY env → saved config.

🫁 PRANA Voice Setup Guide
3
Start Telegram — voice is already on
🤖 AUTOMATIC

Voice is enabled by default — no extra flag needed:

PowerShell
$ prana-telegram
🤖 connected as @my_prana_bot (PRANA) — polling
# if no OpenAI key is found you'll see:
voice: no OpenAI key — voice notes will transcribe/reply as text
(run `prana --save-key` with an OpenAI key for full voice)

To disable voice entirely: prana-telegram --no-voice

✓Verify it works

  • In your PRANA Telegram chat, hold the mic button and say: "summarize what you can do"
  • PRANA transcribes it, thinks, and replies with a playable voice note 🔊
  • Try a follow-up by voice — conversation history carries across voice and text

✚Troubleshooting

Error / symptomFix
🎙️ "I couldn't transcribe that voice note — voice needs an OpenAI API key…"No OpenAI key configured. Run prana --save-key and paste an sk- key.
voice: no OpenAI key — voice notes will transcribe/reply as textStartup warning (not fatal). Voice degrades gracefully to text until an OpenAI key is saved.
Voice note transcribed but reply came as textTTS step failed (check terminal for voice reply failed, falling back to text). Usually a key/quota issue — text fallback is by design.
"transcription came back empty — try a clearer voice note"Whisper got silence or noise. Re-record closer to the mic.
Long replies get cut in audioTTS caps input at 4000 chars — long answers are clipped for speech. Ask for a summary for full voice replies.
