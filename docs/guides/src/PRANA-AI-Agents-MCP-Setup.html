◈What you're building

MCP (Model Context Protocol) is the USB port for AI agents. PRANA ships an MCP server (prana-mcp) that exposes its whole brain — ReAct loop, tools, memory, scheduler — to any MCP-capable agent. After this guide, you can ask Claude Code, Cursor, or ChatGPT Desktop to "use PRANA to schedule a daily briefing" and it just works.

◈The 5 brain tools your agents get

ToolWhat it does
prana_chatRun one task through PRANA's full brain (loop + tools + memory + personality mode). Returns the final answer.
prana_rememberStore a durable fact in long-term memory. Credentials are refused, never stored.
prana_recallSearch long-term memory for relevant snippets.
prana_scheduleCreate a persistent scheduled job (cron / @daily / "every 30m"). The daemon runs it.
prana_jobsList scheduled jobs: name, schedule, active state, delivery target.

API key for prana_chat resolves as: tool arg key → OPENAI_API_KEY / ANTHROPIC_API_KEY / GEMINI_API_KEY env → ~/.prana/config.json. Never logged, never echoed.

1
One-command install: prana-setup
🤖 AUTOMATIC

prana-setup does three things: saves your API key, detects your installed agents, and writes the MCP config for each — merging, never clobbering existing entries.

PowerShell
$ prana-setup
== prana setup — instant installer ==
python: C:\Users\YOU\AppData\Local\Programs\Python\Python314\python.exe

Paste API key (hidden, any provider): ••••••••
API key saved for openai → C:\Users\YOU\.prana\config.json (0600)

agents: Claude Code / Claude Desktop, Cursor
Write MCP configs? [Y/n] y
  Claude Code / Claude Desktop: configured → C:\Users\YOU\.claude.json
  Cursor: configured → C:\Users\YOU\.cursor\mcp.json

Non-interactive flavors

PowerShell
$ prana-setup --key sk-... --yes          # key + all detected agents, no prompts
$ prana-setup --agents claude,cursor        # only these agents
$ prana-setup --dry-run                    # preview what WOULD be written, change nothing
$ prana-setup --check                      # verify installation health anytime
2
Restart your agent apps
👆 YOUR STEP

MCP configs load at app startup. After prana-setup writes them: fully quit and reopen Claude Desktop / Cursor / ChatGPT Desktop (not just the chat — the whole app). CLI agents (Claude Code, Codex CLI, Gemini CLI) pick it up on next launch.

◈Manual setup per agent

Prefer hand control, or want to understand what prana-setup wrote? Each agent, its file, and the exact block. Replace the python path with YOUR full path (see the Windows rule below).

Claude Code %USERPROFILE%\.claude.json
.claude.json — merge into "mcpServers"
{
  "mcpServers": {
    "prana": {
      "command": "C:\\Users\\YOU\\AppData\\Local\\Programs\\Python\\Python314\\python.exe",
      "args": ["-m", "prana.mcp_server"]
    }
  }
}
Claude Desktop %APPDATA%\Claude\claude_desktop_config.json

Same mcpServers.prana block as above. Then fully quit and reopen Claude Desktop.

Cursor %USERPROFILE%\.cursor\mcp.json

Same mcpServers.prana block as above. Then restart Cursor.

Codex CLI / ChatGPT Desktop %USERPROFILE%\.codex\config.toml

TOML format — append this block:

config.toml
# add at the end of the file (idempotent — never duplicate)
[mcp_servers.prana]
command = "C:\\Users\\YOU\\AppData\\Local\\Programs\\Python\\Python314\\python.exe"
args = ["-m", "prana.mcp_server"]

ChatGPT Desktop shares this file with Codex CLI. Verify with /mcp in chat after reopening.

Gemini CLI %USERPROFILE%\.gemini\settings.json

Same mcpServers.prana JSON block as Claude Code.

Antigravity (manual only — no config file)

Agent panel → … → MCP Servers → View raw config → paste:

raw config JSON
{
  "mcpServers": {
    "prana": {
      "command": "C:\\Users\\YOU\\AppData\\Local\\Programs\\Python\\Python314\\python.exe",
      "args": ["-m", "prana.mcp_server"]
    }
  }
}

⚠The Windows full-path rule

⛔ Never use a bare "python"
GUI apps (Claude Desktop, Cursor, ChatGPT Desktop) do NOT inherit your terminal PATH. A bare "command": "python" will silently fail to start the server. Always use the full python path — this is exactly what prana-setup writes automatically.

Find YOUR path (yours will differ — never copy the example blindly):

PowerShell
$ py -c "import sys; print(sys.executable)"
C:\Users\YOU\AppData\Local\Programs\Python\Python314\python.exe
# in JSON, backslashes must be doubled: C:\\Users\\YOU\\...
⚠️ pip ≠ python trap
On some machines pip and python point to different Pythons. Always install with python -m pip install -e . (or py -m pip) using the same interpreter that's in your MCP config. Switched interpreters later? Re-run prana-setup.

✓Verify it works

  • Run prana-setup --check → ends with "All green — PRANA is ready."
  • Restart the agent app (full quit → reopen)
  • In the agent's chat/tools panel, confirm prana appears with its 5 tools
  • Ask it: "use prana_chat to summarize what PRANA can do, teacher mode"

✚Troubleshooting

Error / symptomFix
"No MCP server named prana is currently connected"The server isn't starting. #1 cause: bare python in config (GUI PATH issue) → use the full python path. Then fully quit + reopen the app.
Settings show prana "Enabled" but chat says not connectedSame root cause — the settings UI reads the config, but the server process failed to launch. Fix the command path, restart.
ChatGPT web can't see PRANAExpected — the web app can't run local stdio servers (HTTPS remote only). Use ChatGPT Desktop, which shares ~/.codex/config.toml.
Edited config, agent still doesn't see itMCP configs load at startup. Fully quit and reopen the app — not just the chat window.
prana_chat says "no API key found"Key resolution: tool arg key → env (OPENAI_API_KEY / ANTHROPIC_API_KEY / GEMINI_API_KEY) → ~/.prana/config.json. Run prana --save-key once and it works everywhere.
Tools work, then break after a Python reinstallThe full python path in the config now points nowhere. Re-run prana-setup to rewrite it.
Corrupt JSON config after hand-editingprana-setup never clobbers: it merges into mcpServers and validates. Re-run it to repair.
